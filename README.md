# Защитник.рус — DLE шаблон

Вёрстка лендинга «Контракт на СВО — Гражданину Беларуси» под DataLife Engine.

## Структура

```
templates/zashitnik/
├── main.tpl              главный каркас (header + лендинг + footer)
├── shortstory.tpl        карточка новости в списке
├── fullstory.tpl         полная новость
├── relatednews.tpl       похожие материалы
├── static.tpl            статическая страница
├── info.tpl              системные сообщения движка
├── login.tpl             форма входа / блок профиля
├── searchform.tpl        форма поиска
├── offline.tpl           страница «сайт отключён»
├── sections/             секции лендинга (подключаются {include file=...})
├── css/
│   ├── fonts.css         локальные @font-face (Onest, Tektur)
│   ├── style.css         токены, база, сетка, кнопки, карточки, формы
│   ├── sections.css      @import всех секционных стилей
│   ├── sections/         стили по секциям
│   └── engine.css        служебные стили DLE (пагинация, комментарии, формы)
├── js/main.js            меню, sticky-хедер, аккордеон, маска телефона
├── fonts/                woff2 (cyrillic + latin)
├── images/               графика из Figma
└── index.html            статичное превью лендинга (вне DLE)
```

## Установка в DLE

1. Скопировать папку `templates/zashitnik` в `/templates/` на сервере.
2. Админка → **Настройки скрипта** → *Тема оформления сайта* → `zashitnik`.
3. Проверить, что путь `{theme}` резолвится в `/templates/zashitnik`.

## Страница «статья»

`fullstory.tpl` — обложка с кнопкой «Назад» и датой, заголовок, текст статьи, затем
переиспользуются секции `cta1 → materials-related → contact → footer`.
Статичное превью: `templates/zashitnik/article.html`.

Сверена с макетом (нода `398:1225`, десктоп и `540:4764`, мобильный) — все опорные точки
совпадают: обложка 114, заголовок 638, блоки 965 · 1225 · 1515 · 1675, CTA 1880,
материалы 2470, контакт 3303, подвал 4273; на мобильном 94 · 483 · 710 · 951 · 1128 ·
1531 · 1763 · 2003 · 2793 · 3487 · 4407.

**Врезка в тексте** (ноды `410:2791` / `540:5611`): вертикальная черта — **4px, #D90E0C**
(не 1px и не бирюзовая), длиной чуть короче текстового бокса, поэтому сделана
псевдоэлементом `.article__note::before`, а не `border-inline-start`. Текст врезки на
мобильном — 18px/1.3 (в остальном тексте 16px), отступ от черты 27px.

**Важно:** на странице статьи блок материалов озаглавлен «Читайте также» и без лида —
для этого сделан отдельный `sections/materials-related.tpl` (стили общие, добавлен
модификатор `.materials--related`). Стыки секций на этой странице задаются в
`css/sections/article.css` соседними селекторами (`.article + .cta1` и далее),
поэтому главная страница не затрагивается.

## Ленивая загрузка картинок

Все `<img>` в шаблонах отдают настоящий путь **не в `src`, а в `data-lazy-src`**;
в `src` стоит прозрачный 1×1 GIF (`data:`-строка), поэтому запрос уходит только когда
картинка подходит к вьюпорту. Подменой занимается `IntersectionObserver` в начале
`js/main.js` (`rootMargin: 300px` — картинка успевает прийти до появления на экране).
У каждой картинки заданы атрибуты `width`/`height`, так что подстановка не двигает вёрстку.

Если браузер не знает `IntersectionObserver` — все картинки грузятся сразу (фолбэк в том же модуле).

Для контента, который DLE подгружает аяксом (пагинация, «показать ещё»), доступен
`window.lazyImages(контейнер)` — вызвать после вставки HTML.

**Важно:** изображения внутри `{full-story}` пишет редактор в админке, их этот механизм
не трогает — там работает штатная ленивая загрузка DLE.

## Слайдер материалов

Секция «Полезные материалы» работает на **Swiper 11** (лежит локально: `js/swiper-bundle.min.js`,
`css/swiper-bundle.min.css`, без CDN). Разметка `.materials__slider.swiper` →
`.materials__grid.swiper-wrapper` → `.materials__item.swiper-slide`,
инициализация в `js/main.js` (`slidesPerView:'auto'`, шаг карточек 39px как в макете,
стрелки `.materials__nav-btn--prev/--next`, клавиатура, a11y-подписи).

## Адаптив

Горизонтальной прокрутки нет ни на одной ширине: 1600 / 1440 / 1366 / 1280 / 1180 / 1024 /
900 / 834 / 768 / 600 / 430 / 390 / 360. На `html` и `body` стоит `overflow-x: clip`
(не `hidden` — clip не создаёт контекст прокрутки и не ломает `position: sticky`).

Брейкпоинты: **1200 / 1040 / 900 / 600**. На 1200 фото с флагами в секции «Кто может подписать»
уходит из абсолютного позиционирования в поток — иначе на 1024 оно перекрывало текст карточек.

### Что оказалось критичным для 1:1

- **Фон первого экрана** — снимок неба **плюс пелена** `rgba(255,255,255,.44)` отдельным слоем.
- **`--container: 1440px`** при `padding-inline: 20px` → контент ровно **1400px**, как в макете.
- **Абсолютные потомки `.container`** отсчитываются от padding-box, поэтому у них
  `left: 21px` / `right: 20px`, а не `0`.
- **Кадрирование фотографий** задано в макете индивидуально (`width/height/left/top` в процентах),
  а не через `object-fit: cover`. Значения вынесены в CSS для каждой карточки материалов,
  фото выплат и фото формы. Фото в секции «Контакт» вдобавок **отзеркалено** (`scaleX(-1)`).
- **Иконки** собраны из настоящих Figma-фрагментов. У фрагментов есть собственная система
  координат — им нужен `transform: scaleY(-1)` (для шагов) или общий
  `translate(0,100) scale(1,-1)` на группу (для секции «Кто может подписать»);
  без этого рисунок получается перевёрнутым.
- **Круг в кнопках** — контур `1px rgba(255,255,255,.4)`, а не заливка.
- **Маркер списка** — точка 5px со сдвигом `-18px`, а не стандартный `list-style: disc`.
- **Номер в карточке «Документы» обрезан линией.** В Figma координаты текста — это бокс чернил,
  а не line-box CSS, поэтому цифра заканчивается ровно на линии. Реализовано как
  `.docs__num{height:60px;overflow:hidden}` + линия через `::after` — иначе низ цифры торчит
  под линией и выглядит как зачёркивание.
- **Скрытый `<br>` требует пробела перед собой.** На мобильном перенос в первом экране прячется
  (`.hero__text br{display:none}`), и без пробела слова склеивались в «граждан­Беларуси».
- **Фигма-стрелки из «Send»-групп нельзя вставлять как есть.** В макете они лежат повёрнутыми
  (`rotate(-135deg) scaleY(-1)`), поэтому одиночный SVG-фрагмент смотрит не туда. Во всех кнопках
  стрелка нарисована инлайном.
- **Кадрирование фотографий на мобильном пришлось выводить обратным счётом** — размер и положение
  подобраны так, чтобы верх лица и ширина лица совпали с эталоном (первый экран: 555/117 против
  макетных 561/117). Точных fill-трансформов мобильного макета получить не удалось из-за лимита API.
- **Иконки мессенджеров экспортированы под тёмный фон** (`fill="white"`). Для белой панели меню
  сделаны красные копии, для тёмного подвала — белая копия MAX. В подвале иконки выводятся
  через `mask-image` + `background-color`, иначе цвет на ховере не поменять (`<img>` не красится).
- **Служебные стили `engine.css` для `{full-story}` протекают в размеченную статью.**
  Правила `.article__body h2 / ul / li` перебивают классы секции, поэтому в `article.css`
  селекторы усилены префиксом `.article`.
- **`{theme}` — тег DLE и в CSS не раскрывается.** Иконка чекбокса из-за этого не грузилась;
  переведена в инлайновый `data:`-URI. В CSS путей вида `{theme}/...` быть не должно.
- **Вертикальный ритм** секций вынесен в `css/style.css` отдельным блоком: значения выведены
  из расстояний между опорными точками макета, а не заданы одинаковым `padding`.

## Заметки по реализации

- **Изображения**: растр из Figma сконвертирован в WebP (39 МБ → 2,1 МБ), ширина ограничена 1600px.
  Неиспользуемые фрагменты SVG удалены.
- **Sticky-хедер**: в макете есть отдельная нода прокрученного состояния (`99:484`) — она реализована
  не отдельным блоком, а классом `.header.is-stuck`, который вешает JS после 120px прокрутки.
  Геометрия совпадает с макетом: логотип 100/43 250×30, меню прижато к кнопкам с зазором 34px,
  телефон 1116/33 188×44, CTA 1314/33 186×44, высота полосы 101px.
  **Сознательное отступление**: в макете у прокрученного состояния другие пункты меню
  («Сопровождение», «Документы» вместо «Вопросы», «Материалы»). Подмена подписей при скролле
  сбивает пользователя и выглядит как недоделка макета, поэтому меню одно — из первого экрана.
  Если нужно ровно как в макете — скажите, добавлю второй набор ссылок.
- **Иконки шагов**: Figma отдала часть иконок разрезанными на фрагменты; там, где фрагменты
  нечитаемы, нарисованы чистые inline-SVG той же семантики.
- **FAQ**: на нативных `<details>/<summary>` — работает без JS.
- **Вкладки выплат**: `role="tablist"` + клавиатурная навигация стрелками (`js/main.js`).
- **Превью**: `templates/zashitnik/index.html` — статичная сборка всех секций, открывается без DLE.
  Пересобрать после правок можно скриптом сборки (склеивает `sections/*.tpl` и `css/sections.css`).
